# 🛒 Grandma Market — 2D Simulation Game
> **Solo Developer Project** | Unity & C# | 1 เดือน (2025)


รับบทเป็นเด็กหนุ่มผู้ต้องเข้ามาดูแลกิจการร้านค้าต่อจากคุณยายที่กำลังล้มป่วย ผู้เล่นจะต้องบริหารจัดการร้าน รับมือกับลูกค้ามากหน้าหลายตาที่เข้ามาใช้บริการ และทดสอบทักษะการจัดการเวลาเพื่อนำพาร้านค้าของครอบครัวให้รอดพ้นวิกฤต

---

## 🎮 Game Interface & Mechanics (อธิบายส่วนต่างๆ ในเกม)

- **🛒 ร้านค้าและ สินค้า** พื้นที่สำหรับจัดวางสินค้าประเภทต่างๆ ที่ผู้เล่นต้องคอยเติมของและหยิบให้ลูกค้า

[](image.png)

- **🧍‍♂️ ระบบลูกค้า NPC (Customer Demand System):** ลูกค้าจะเดินเข้าร้านพร้อมกับแสดงความต้องการสินค้าและเกจเวลารอคอย (Patience Bar)
- **⏱️ ระบบจัดการเวลา (Time & Patience Mechanics):** หากลูกค้ารอนานเกินไป ระดับความพึงพอใจจะลดลงและออกจากร้านโดยไม่จ่ายเงิน
